# CortexOnyx

Agentic AI and SEO, done for you — by [Logique Onyx](https://logiqueonyx.com), Montreal.

CortexOnyx makes sure a customer trying to reach a local business never gets lost, and the owner never has to think about it: visibility audits, missed-call text-back, review automation, lead follow-up, and a weekly owner summary — productized automations that run on one reusable platform core.

## This repository

The public home of the CortexOnyx platform:

- `STATIC.md` — the agent's static layer: identity, mission, voice, and hard rules (v0.1)
- `docs/3-pillar-blueprint.md` — the design blueprint: static concept / dynamic concept / skills, wrapped in deterministic guardrails (CASL consent checks, approval gates, full event log)
- The open-source web crawler for SEO audit data lives here as it is built

Client configurations and client data are never stored in this repository.

## Status

Phase 0 — design committed; build phases are gated on client pilots.
